# Página Web Personal

Este proyecto consiste en la creación de una **página web personal** desarrollada como parte de un trabajo universitario.
El objetivo es mostrar información personal utilizando tecnologías básicas de desarrollo web.

## Descripción

La página web presenta información personal del autor, organizada en una interfaz sencilla y estructurada.
El proyecto fue desarrollado utilizando **Visual Studio Code** y está compuesto por archivos HTML, CSS y JavaScript para estructurar, diseñar y agregar funcionalidad a la página.

## Tecnologías utilizadas

* python
* Visual Studio Code

## Estructura del proyecto

El proyecto está organizado de la siguiente manera:

```
AndresFHR2002.github.io
│
├── index.html
├── css
│   └── styles.css
└── js
    └── main.js
```

### Descripción de los archivos

* **index.html**
  Contiene la estructura principal de la página web y la información general mostrada en el sitio.

* **css/styles.css**
  Se encarga del diseño visual de la página, incluyendo colores, estilos y aspectos estéticos.

* **js/main.js**
  Contiene el código JavaScript utilizado para agregar funcionalidad a la página, como la gestión del título y posibles interacciones.

## Cómo ejecutar el proyecto

Para visualizar la página web:

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo **index.html** en cualquier navegador web.

También puede abrirse directamente desde un editor como **Visual Studio Code** usando una extensión de servidor local.
